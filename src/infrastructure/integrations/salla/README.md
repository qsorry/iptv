# استيراد من سلة

مسؤولية هذا المجلد: نقل بيانات تاجر من متجر سلة إلى المنصة.

المصادر المخطط لها:
1. **ملف Excel/CSV** الذي تصدره سلة من صفحة المنتجات (الأسهل للتاجر).
2. **Salla Merchant API** بعد ربط التطبيق (منتجات، تصنيفات، عملاء، طلبات).

الملفات المتوقعة:
- `excel-importer.ts` — يقرأ الملف ويحوّله إلى `CreateProductInput[]`.
- `api-client.ts` — عميل REST لواجهة سلة.
- `mappers.ts` — تحويل حقول سلة إلى نموذج المنصة.
